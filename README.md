# Responsive Pricing Cards UI – React

A modern and responsive pricing cards interface built using **React.js, JavaScript, and CSS**. This project demonstrates reusable React components, dynamic data rendering using `.map()`, and responsive web design.

## 🚀 Features

- **Reusable Components:** Built using a reusable `PricingCard` component.
- **Dynamic Rendering:** Pricing plans and features are rendered dynamically using `.map()`.
- **Responsive Design:** Adapts to desktop, tablet, and mobile screens.
- **Font Awesome Icons:** Displays check and cross icons for available and unavailable features.
- **Hover Effects:** Interactive card animations and button hover effects.
- **Modern UI:** Clean card layout with a blue gradient background.
- **Separate Data File:** Pricing plan data is maintained independently from the UI components.

## ⚙️ Getting Started


## 📱 Responsive Design

The interface adapts to different screen sizes:

- **Desktop:** Pricing cards displayed in a row.
- **Tablet:** Cards wrap into multiple rows when necessary.
- **Mobile:** Cards are stacked vertically for a better viewing experience.
